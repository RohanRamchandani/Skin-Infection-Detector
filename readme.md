🧠 DermaDetect: AI-Powered Skin Infection Analysis

DermaDetect is a full-stack AI application designed to provide preliminary analysis of common skin infections. By leveraging deep learning and computer vision, the platform classifies user-uploaded images and provides supplemental wellness recommendations, emphasizing ethical data handling and user safety.

🚀 Key Features

1. AI Diagnostics: Utilizes advanced Convolutional Neural Networks (CNNs) to identify common skin conditions from images.
2. High-Accuracy Modeling: Trained on a balanced, custom dataset of 14,000+ images using Transfer Learning (EfficientNet/ResNet) to achieve ~75% accuracy.
3. Automated Recommendations: Integrated logic engine that suggests supplements and care routines based on the detected diagnosis.
4. Production-Ready Deployment: Containerized using Docker for consistent environment management and scalable model serving.
5. Privacy & Ethics: Built-in safety disclaimers and ethical data handling protocols to protect user privacy.

🏗️ Technical Stack

1. Frontend: React, React Native (Mobile)
2. Backend: Python, Flask, TensorFlow/Keras
3. Deep Learning: CNNs, EfficientNet, ResNet
4. DevOps & Tools: Docker, Git, GitHub Actions, VS Code

🛠️ Project Impact

Optimized Performance: Improved classification through rigorous preprocessing, experimentation, and dataset balancing.
End-to-End Integration: Successfully bridged the gap between a complex ML model and a user-friendly interface, managing the full data pipeline from upload to inference.
